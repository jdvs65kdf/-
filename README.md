# Автоматизована система управління бібліотекою

Консольна програма на Python для обліку книжкового фонду, читачів і видачі книг.
Розроблена в межах курсової роботи «Розробка автоматизованої системи управління
бібліотекою з використанням принципів об’єктно-орієнтованого програмування».

## Можливості

- облік паперових (з номером полиці) та електронних (з розміром файлу і форматом) книг;
- додавання, вилучення та перегляд книг, пошук за частиною назви або імені автора;
- реєстрація читачів і перегляд їхнього списку разом із виданими книгами;
- видача книги читачеві та прийом її назад з перевіркою стану;
- збереження даних у файл `library_data.json` (UTF-8) і автоматичне завантаження під час запуску.

## Вимоги та запуск

Потрібен Python 3.8 або новіший, сторонні бібліотеки не використовуються.

```bash
python main.py
```

Роботу слід завершувати через пункт меню 9 «Зберегти та вийти» — саме тоді дані записуються у файл.

## Структура класів

| Клас | Призначення | Основні методи |
|---|---|---|
| `Book` | базовий клас книги: ID, назва, автор, рік (доступні через `@property`), стан видачі | `get_info()`, `to_dict()`, `from_dict()` |
| `PaperBook(Book)` | паперова книга, додає номер полиці | `get_info()`, `to_dict()` (перевизначені) |
| `EBook(Book)` | електронна книга, додає розмір файлу і формат | `get_info()`, `to_dict()` (перевизначені) |
| `Reader` | читач: ID, ПІБ, телефон, список ID виданих книг | `to_dict()`, `from_dict()` |
| `LibraryManager` | зберігає словники книг і читачів, правила видачі та повернення, робота з файлом | `search_books()`, `issue_book()`, `return_book()`, `save_data()`, `load_data()` |

Функція `main()` реалізує текстове меню: зчитує вибір користувача, створює об’єкти
`Book`/`Reader` і передає їх до `LibraryManager`.

## Застосовані принципи ООП

- **Інкапсуляція** — атрибути книги приховані (`_id`, `_title`, …) і доступні лише для читання; правила видачі зосереджені в `LibraryManager`.
- **Успадкування** — `PaperBook` і `EBook` розширюють `Book`, викликаючи `super()`.
- **Поліморфізм** — `get_info()` перевизначено в нащадках, тому каталог виводиться без перевірки типу книги; `Book.from_dict()` за полем `type` відновлює об’єкт потрібного класу.
- **Абстракція** — моделюються лише ті властивості книг і читачів, що потрібні для обліку.

## Формат файлу даних

```json
{
  "books": [
    {"type": "PaperBook", "book_id": "P001", "title": "Кобзар", "author": "Тарас Шевченко",
     "year": 1840, "is_issued": false, "shelf_number": "A1"},
    {"type": "EBook", "book_id": "E001", "title": "Чистий код", "author": "Роберт Мартін",
     "year": 2008, "is_issued": false, "file_size_mb": 5.4, "format_type": "PDF"}
  ],
  "readers": [
    {"reader_id": "R001", "name": "Коваленко Олена Петрівна", "phone": "0671234567",
     "borrowed_books": []}
  ]
}
```
